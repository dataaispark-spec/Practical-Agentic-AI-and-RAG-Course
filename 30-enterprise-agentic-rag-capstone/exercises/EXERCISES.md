# Module 30 Exercises — Enterprise Agentic RAG Capstone

## Exercise 1 — Architecture
Choose workflow, RAG, agent or multi-agent for three enterprise scenarios. Record capability gained, rejected alternative, risk, KPI and rollback.

## Exercise 2 — Grounded retrieval
Add tenant-filtered evidence and require citation-supported completion.

## Exercise 3 — Tool governance
Add a read-only tool and an approval-gated mutation. Write tests for unauthorized requests and duplicate effects.

## Exercise 4 — Failure injection
Break retrieval, provider availability, tool authorization and verification. Document symptom, first broken invariant, containment, recovery and regression test.

## Exercise 5 — Production review
Produce an ADR covering latency, cost, quality, security, observability and deployment gates.

### Gold challenge
Integrate the capstone with the graph modules that follow while preserving deterministic policy and independent verification.
