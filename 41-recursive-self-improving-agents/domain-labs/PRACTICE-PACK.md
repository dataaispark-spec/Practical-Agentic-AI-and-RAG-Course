# Module 41 Practice Pack

## Domain labs
**Prompt optimization:** improve failure cases while holding safety constant.
**Retrieval optimization:** tune query/ranking without contaminating held-out evaluation.
**Tool routing:** reduce unnecessary calls while preserving verified success.
**Recovery optimization:** improve recovery policies without weakening termination.
**Skill improvement:** propose a new skill from trajectories and gate it through regression tests.

## Benchmark
Baseline vs 3 candidates on fixed, adversarial and held-out suites. Track quality delta, safety regression, cost delta, latency delta, verifier agreement, experiment count and rollback rate.

## Mastery
Demonstrate evaluator capture against a weak benchmark, then isolate the evaluator, harden the suite and show the candidate still generalizes. Prove recursive depth/time/cost limits and immutable improvement provenance.
