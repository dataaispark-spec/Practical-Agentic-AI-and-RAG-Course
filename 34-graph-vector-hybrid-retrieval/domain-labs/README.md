# Module 34 — Domain Lab Pack

## Cybersecurity
Fuse advisory vectors with `Asset → Vulnerability → Control → Owner` paths.

## Banking
Fuse transaction/policy text with `Customer → Account → Transaction → Case → Policy` constraints.

## Healthcare
Fuse literature retrieval with `Drug → Condition → Guideline → Evidence` paths and provenance.

## Manufacturing
Fuse maintenance passages with `Machine → Component → FailureMode → WorkOrder` paths.

## Enterprise IT
Fuse incident/runbook vectors with `Service → Dependency → Team → Incident → Runbook` paths.

## Assessment
For each domain compare vector-only, graph-only, RRF and reranked hybrid. Include one semantic query, one multi-hop query, one poisoned-subgraph case and one authorization-order case.
