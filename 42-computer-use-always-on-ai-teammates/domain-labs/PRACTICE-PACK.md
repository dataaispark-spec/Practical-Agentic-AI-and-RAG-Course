# Module 42 Practice Pack

## Domain labs
**CRM:** update records through API-first and UI fallback; verify exact account state.
**Service desk:** triage and resolve tickets through a synthetic browser; survive stale pages and session expiry.
**Finance operations:** synthetic approval-gated submissions with credential brokering and DLP.
**Procurement:** compare structured integration with browser automation.
**CI/CD:** operate a synthetic deployment console with emergency shutdown.

## Benchmark
Compare API-first, native-integration and computer-use execution. Measure verified task success, stale-action rate, unsafe attempts, approvals, recovery, UI actions, latency and cost.

## Mastery
Defeat webpage prompt injection, stale UI, wrong-account state and expired approval. Prove credentials never enter ordinary model context and consequential actions have postcondition verification.
