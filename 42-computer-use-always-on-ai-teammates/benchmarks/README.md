# Module 42 Benchmark Contract

Run identical synthetic workflows through API-first, native-integration and computer-use paths.

Measure verified success, action success, stale-action rate, verification failure, unsafe attempts, approval rate, recovery rate, UI actions/task, latency/task and cost/task.

Adversarial set: webpage injection, wrong-account state, stale DOM, popup/navigation change, expired approval, session expiry, duplicate submission and DLP trigger.

A computer-use architecture must earn its complexity through measurable coverage where structured interfaces are insufficient.
