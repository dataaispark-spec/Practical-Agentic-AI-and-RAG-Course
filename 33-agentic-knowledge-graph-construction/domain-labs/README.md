# Module 33 — Domain Lab Pack

## Cybersecurity
Agent extracts `CVE → Product → Version → Asset → Control`; high-risk remediation relations require approval.

## Banking
Agent proposes `Customer → Account → Transaction → Case → Policy`; evidence and approval are mandatory for risk-changing knowledge.

## Healthcare
Agent proposes `Drug → Condition → Guideline`; unsupported clinical claims are quarantined.

## Manufacturing
Agent constructs `Machine → Component → FailureMode → WorkOrder`; contradictory maintenance facts enter review.

## Enterprise IT
Agent constructs `Service → Dependency → Incident → Team → Runbook`; ticket text is untrusted data and cannot issue graph-write instructions.

## Assessment
Each track requires labeled extraction, adversarial source text, entity ambiguity, contradiction, tenant isolation, idempotent retry and rollback evidence.
