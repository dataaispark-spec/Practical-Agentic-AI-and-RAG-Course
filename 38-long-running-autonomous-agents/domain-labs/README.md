# Module 38 Domain Labs

## Banking
Build a durable settlement-exception worker. Inject duplicate delivery, timeout-after-write and approval expiry. Prove effectively-once correction and reconcile against the ledger.

## Cybersecurity
Run a 6-hour SOC investigation across alerts, asset data and tickets. Pause for analyst approval, survive worker restart and revalidate policy before containment.

## SRE
Design an overnight migration/remediation worker with prechecks, checkpoints, rollback and an SLA budget.

## Enterprise IT
Process change requests from queue to implementation with leases, fencing, CAB approval and audit reconstruction.

## Research
Perform staged evidence collection where some steps wait for external responses. Measure wakeups, context growth and cost per verified conclusion.

Every lab must produce a failure matrix, recovery proof and cost/SLO analysis.
