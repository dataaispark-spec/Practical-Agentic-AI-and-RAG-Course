# Module 40 Practice Pack

## Domain labs
**Coding:** execute code in a resettable sandbox and verify tests independently.
**SOC:** simulate containment actions and verify final asset state, not model claims.
**SRE:** migrate a service in a synthetic environment and verify invariants.
**Procurement:** optimize workflow reward while preserving approval and budget constraints.
**Support:** solve tickets where weak rewards can be gamed by producing plausible text.

## Benchmark
Compare weak reward, deterministic verifier, model judge and hybrid verifier. Report false accept/reject rates, success, pass@k, steps, cost, latency and held-out generalization.

## Mastery
Exploit a weak verifier, harden it, prove the exploit fails, and demonstrate that legitimate solutions still pass. Preserve evaluator independence and seeded replay.
