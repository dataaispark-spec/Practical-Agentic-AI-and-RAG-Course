# Module 32 — Domain Lab Pack

## Cybersecurity
Reconstruct `Asset → Vulnerability → Control` as-of an incident date. Exercise late-arriving advisories and stale-control detection.

## Banking
Model policy versions and ask which policy governed a transaction on a historical date. Include late regulatory corrections.

## Healthcare
Maintain effective/expired guideline relationships. Prove current queries exclude expired guidance while audits can retrieve it.

## Manufacturing
Track component ownership/substitution intervals and detect overlaps.

## Enterprise IT
Version service dependencies by release and reconstruct the dependency graph during an outage.

## Assessment
Each domain must include historical queries, one late-arriving correction, one contradiction, one overlap defect, one tenant/ACL test and one rollback exercise.
