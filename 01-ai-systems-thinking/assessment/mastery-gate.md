# Module 1 Mastery Gate

## Pass standard

A learner passes only when the evidence shows both implementation skill and architectural reasoning.

### Build

- [ ] Architecture Decision Engine runs locally.
- [ ] At least 10 automated tests pass.
- [ ] Industry exercises are completed.
- [ ] Architecture diagram is readable without verbal explanation.
- [ ] ADR is complete.

### Reason

- [ ] Explain deterministic software vs LLM app vs RAG vs agent vs multi-agent.
- [ ] Explain why the selected architecture is the minimum sufficient design.
- [ ] Explain at least three rejected alternatives.
- [ ] State measurable success criteria.

### Debug

Given a deliberately flawed AI architecture, identify:

1. the highest-impact correctness risk
2. the highest-impact security risk
3. the highest-impact reliability risk
4. the highest-impact cost/latency risk
5. the evidence needed to confirm each diagnosis

### Interview defense

In 10 minutes, present:

```text
Problem
  -> Requirements
  -> Architecture choice
  -> Diagram
  -> Implementation
  -> Failure mode
  -> Measurement
  -> Improvement
  -> Trade-offs
```

### Stretch target

Improve the decision engine so the same requirement set can return:

- recommended pattern
- reasons
- alternatives
- assumptions
- risks
- required controls
- revisit triggers

The stretch implementation becomes a foundation for later production architecture decision support.
