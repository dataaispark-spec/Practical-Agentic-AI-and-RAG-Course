# Module 43 Practice Pack

## Capstone domain choices
SOC investigation; SRE incident/remediation; banking reconciliation; enterprise research; coding teammate; procurement; customer operations.

## Progressive build
1. deterministic workflow;
2. RAG evidence;
3. GraphRAG/hybrid retrieval;
4. governed loop;
5. durable execution;
6. memory/skills;
7. verifier environment;
8. computer-use bridge;
9. controlled improvement.

## Final benchmark
Compare simple workflow, baseline agent, guarded agent and frontier system on identical cases. Measure Recall@K/MRR, multi-hop accuracy, groundedness, citation correctness, task success, verifier precision/recall, safety violations, recovery/resume success, p95 latency, cost/success, trace completeness and improvement regression.

## Chaos graduation
Inject retrieval miss, stale graph, tenant leak, malformed tool call, provider outage, duplicate mutation, false verification, checkpoint corruption, poisoned memory/skill, UI injection and evaluator regression. Every failure requires detection, containment, recovery and regression evidence.
